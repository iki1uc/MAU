## QI · IQQ · GEO · MODUL — Systemklärung

Dieses Dokument erklärt die vier zentralen Achsen des iki1uc‑Systems:

- **[QI](ca://s?q=QI_Achse)** — gerichtete 12×360°‑Rotation  
- **[IQQ](ca://s?q=IQQ_Achse)** — halbe 6×360°‑Rotation  
- **[GEO](ca://s?q=GEO_Form)** — Formkörper (IX)  
- **[MODUL](ca://s?q=MODUL_Kern)** — Kernkörper (XI)  

Diese vier bilden die Grundlage für die 6‑Achse:

1. **[PORT](ca://s?q=PORT_System)**  
2. **[MAIN](ca://s?q=MAIN_System)**  
3. **[KIpi](ca://s?q=KIpi_Process)**  
4. **[Stationen](ca://s?q=Stationen_iki1uc)**  
5. **[NEI LIBERTY](ca://s?q=NEI_LIBERTY)**  
6. **[PORT IN/OUT](ca://s?q=PORT_IN_OUT)**

## QI · 12×360° · gerichtete Rotation

**QI** ist die höchste Rotations‑Achse des Systems.  
Sie beschreibt eine **vollständige, gerichtete Bewegung**, die 12‑fach um 360° rotiert.

- 12 × 360° = **4320°**  
- gerichtete Achse  
- vollständige Ausrichtung  
- höchste Präzision  
- wird in **TMPCHAIN** genutzt  
- trägt die interne Kette:

QI: ◉ → 3 → ◎ → ◆ → △ → ▣ → 81 → 756 → 27 → 3 ↺


**QI** wird verwendet für:

- Tiefen‑Analyse  
- gerichtete Bewegungen  
- vollständige Ausrichtung  
- Meta‑Rotationen  
- interne TMP‑Führung

---

## IQQ · 6×360° · halbe Rotation

**IQQ** ist die halbe Rotations‑Achse des Systems.  
Sie beschreibt eine **halbgerichtete Bewegung**, die 6‑fach um 360° rotiert.

- 6 × 360° = **2160°**  
- halbe Achse  
- mittlere Präzision  
- wird in **TMPCHAIN** genutzt  
- trägt die interne Kette:

IQQ: 3 → 9 → 81 → 756 → 27 → 3 ↺


**IQQ** wird verwendet für:

- mittlere Bewegungen  
- Zwischen‑Frames  
- Public‑Rotationen  
- ON3‑Relativität  
- Frame‑Wechsel

## GEO · Formkörper (IX)

**GEO** ist der **Formkörper** des Systems.  
Er definiert die **äußere Struktur**, die **Bewegungsformen**, die **Gestalt**.

GEO besteht aus 9 Bewegungsformen:

- **[PUSH](ca://s?q=PUSH_Form)**  
- **[PULL](ca://s?q=PULL_Form)**  
- **[SHIFT](ca://s?q=SHIFT_Form)**  
- **[FLOW](ca://s?q=FLOW_Form)**  
- **[BREAK](ca://s?q=BREAK_Form)**  
- **[SPIN](ca://s?q=SPIN_Form)**  
- **[RISE](ca://s?q=RISE_Form)**  
- **[DROP](ca://s?q=DROP_Form)**  
- **[ROOT](ca://s?q=ROOT_Form)**  

GEO ist:

- sichtbar  
- öffentlich  
- strukturell  
- formgebend  
- IX‑Ebene

GEO ist die **Form**, die später durch MODUL und MAIN ausgeführt wird.

## MODUL · Kernkörper (XI)

**MODUL** ist der **Kernkörper** des Systems.  
Er trägt die **Bedeutung**, die **Logik**, die **Axiome**.

MODUL besteht aus:

- **PORT** (Übergang)  
- **KIpi** (Pipeline)  
- **Axiom 0.33 → 0.66 → 0.99**  

### PORT  
- 0.33 Eingang  
- 0.66 Verarbeitung  
- 0.99 Ausgang  

### KIpi  
- **[allIN](ca://s?q=allIN_Definition)**  
- **[process](ca://s?q=KIpi_Process)**  
- **[allOUT](ca://s?q=allOUT_Definition)**  

### Axiom  
- Ursprung  
- Mitte  
- Spitze  
- whirl‑Dreieck

MODUL ist:

- bedeutungstragend  
- stabil  
- logisch  
- XI‑Ebene  
- Kern des Systems
